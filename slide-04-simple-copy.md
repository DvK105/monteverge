# Slide 04 — How the model moves the gap (simple version)

## Headline
**Where could each Tata stock go from here?**

## The idea, plainly
A stock's gap doesn't stay where it is. It gets pulled back toward normal — like a ball rolling to the bottom of a bowl. The farther the gap is from normal, the stronger the pull.

But random shocks keep knocking the ball off course.

So the model doesn't predict one future. It runs the same simple step over and over — day after day, on many paths — to build many possible futures. Each grey line is one possible future. The red line is where they average out: back toward normal.

## The rule (2 steps)
1. **The model** → change = pull + shock  
   Pull grows with distance. Shock is random.

2. **One day forward** → next = now + pull + shock  
   Repeat for every day, on every path.

## Worked example (one day, four moves)
| | |
|---|---|
| Start | today's gap |
| Pull | toward normal |
| Shock | random kick |
| Result | tomorrow's gap |

Repeat the loop to build a possible future.

## Why this matters (leads into the next slide)
Now we have many possible futures for each stock. The next question: which of them are likely, and which are just noise? That's what the next slide looks at.
